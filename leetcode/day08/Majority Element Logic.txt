🔹 Step 1: Initialize Variables
int candidate = 0;
int count = 0;


candidate → number we think might be majority

count → how confident we are about the candidate

🔁 Step 2: Traverse the Array

We go one element at a time.

🟢 Element 1 → 2

count == 0 → choose new candidate

candidate = 2
count = 1


🧠 Meaning: “I think 2 might be majority.”

🟢 Element 2 → 2

Same as candidate → increase confidence

count = 2

🔴 Element 3 → 1

Different from candidate → decrease confidence

count = 1

🔴 Element 4 → 1

Different again → decrease confidence

count = 0


🧠 Meaning: “I am no longer confident about candidate 2.”

🟢 Element 5 → 1

count == 0 → choose new candidate

candidate = 1
count = 1

🔴 Element 6 → 2

Different → decrease confidence

count = 0

🟢 Element 7 → 2

count == 0 → choose new candidate

candidate = 2
count = 1

🔚 Step 3: End of Loop

Final value:

candidate = 2

✅ Step 4: Return Candidate
return candidate;
