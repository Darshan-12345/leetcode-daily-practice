🔹 Step 1: Initialize
map = {0=1}
sum = 0
count = 0


👉 Why {0=1}?

It helps count subarrays that start from index 0

🔹 Step 2: Loop through array
➤ First number: 1
sum = 1
sum - k = -1 → not in map
map = {0=1, 1=1}

➤ Second number: 1
sum = 2
sum - k = 0 → FOUND in map
count += 1 → count = 1
map = {0=1, 1=1, 2=1}


Subarray: [1,1]

➤ Third number: 1
sum = 3
sum - k = 1 → FOUND in map
count += 1 → count = 2
map = {0=1, 1=1, 2=1, 3=1}


Subarray: [1,1] (from index 1)

✅ Final Answer
count = 2

🔹 Example 2
nums = [1,2,3], k = 3


Valid subarrays:

[1,2]

[3]

Answer = 2

🧠 WHY THIS WORKS (INTUITION)

We keep track of prefix sums

For each new sum, we check:

“Have I seen a prefix sum that makes current sum = k?”

HashMap gives O(1) lookup
