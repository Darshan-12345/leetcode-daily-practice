🔹 Step 1: Create Count Array
int[] count = new int[26];


This stores how many times each letter appears.

Index meaning:

0 → 'a'
1 → 'b'
2 → 'c'
...
25 → 'z'

🔹 Step 2: Count Magazine Letters
for (char c : magazine.toCharArray()) {
    count[c - 'a']++;
}


For "aab":

Letter	Index	Count
a	0	2
b	1	1
🔹 Step 3: Try to Build Ransom Note
for (char c : ransomNote.toCharArray())

First 'a'

count[0] = 2 → OK

Decrease to 1

Second 'a'

count[0] = 1 → OK

Decrease to 0

🔹 Step 4: Success

All letters found → return true

❌ Failure Example
ransomNote = "aa"
magazine = "ab"


Counts:

a = 1
b = 1


Second 'a' → count is 0 → return false

⏱ Time & Space Complexity
Metric	Value
Time	O(n + m)
Space	O(1) (fixed 26 array)
