🔹 Step 1: Pick first string as prefix
prefix = "flower"

🔹 Step 2: Compare with second string "flow"

"flow" does NOT start with "flower"

Shorten prefix:

"flower" → "flowe" → "flow"


Now "flow" starts with "flow" ✅

🔹 Step 3: Compare with third string "flight"

"flight" does NOT start with "flow"

Shorten prefix:

"flow" → "flo" → "fl"


Now "flight" starts with "fl" ✅

🔹 Step 4: End loop
Answer = "fl"

❌ Example 2
strs = ["dog","racecar","car"]


prefix = "dog"

"racecar" does NOT start with "dog"

prefix reduces to empty

👉 return ""

Metric	Value
