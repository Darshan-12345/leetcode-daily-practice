STEP 1️⃣ Count frequency (using HashMap)
Map<Integer, Integer> freqMap = new HashMap<>();


For each number:

freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);


Example:

{1=3, 2=2, 3=1}

STEP 2️⃣ Create buckets (Array of Lists)
List<Integer>[] buckets = new List[nums.length + 1];


Why nums.length + 1?

Maximum frequency possible = array size

STEP 3️⃣ Put numbers into buckets
for (int num : freqMap.keySet()) {
    int freq = freqMap.get(num);
    if (buckets[freq] == null) {
        buckets[freq] = new ArrayList<>();
    }
    buckets[freq].add(num);
}


Now buckets look like:

index 1 → [3]
index 2 → [2]
index 3 → [1]

STEP 4️⃣ Collect top k elements

Start from highest frequency:

for (int i = buckets.length - 1; i >= 0 && result.size() < k; i--)


Add elements until we have k.
